Vlog detail — six designs

Six takes on the single vlog page — the vlog equivalent of BlogPost.jsx. Every one of them is a hub, not just a player: the video, its chapters, the frame grabs, the ride route drawn from real coordinates, the Instagram reels from the same trip, the blog posts that cover the same ground, and the rest of the channel. Pick a different video from the dropdown to see how each holds up for a 24-second short as well as an 18-minute film. Flip Empty for the state that ships while garage.vlogs is still empty.
Standalone HTML in this folder, all reading vlog-data.js — the same file the section designs use. Open from the file system so the local clips and photos resolve.
