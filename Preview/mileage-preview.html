Mileage section — eighteen designs

Eighteen ways to put one mileage reading on /mygarage. No fuel log, no history — the figure the Bear actually returns, plus the handful of things that fall out of it. Every design reads the same numbers from mileage-data.js; change the reading there and all eighteen follow. Flip Empty to see how each behaves before a reading has been taken.
Standalone HTML in this folder. Open from the file system — mileage-data.js and mileage-motion.js load as sibling scripts. Both are classic scripts, not modules, so file:// works.
