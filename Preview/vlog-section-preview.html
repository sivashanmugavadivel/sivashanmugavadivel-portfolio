Vlog section — twelve designs

Twelve ways to put the vlogs on /mygarage, each a different idea about what a video list is. All of them show five vlogs and carry a way through to /videos for the rest — each in its own idiom. Every one also ships an empty state, since garage.vlogs is still empty — flip Empty to see it.
Standalone HTML in this folder, all reading the same content from vlog-data.js. Open from the file system so the local clips and photos resolve.
